# 米的地图 · MI’S MAP

[打开游戏](https://mi.fivsevn.com)

一个以地图和手机为入口的像素旅行游戏。当前非洲旅行共 42 天，分为七段、74 个事件；每段结束后可以暂回地图，再从下一站继续同一次旅行。行李、余额、聊天和笔记持续保存，整卷结束后才进入归来整理。

首页世界地图可拖动，点击非洲进入地区地图。地点统一以小方块表示；下一站可进入，已到访地点可查看记录，后续地点暂不可进入。游戏画面右下角的迷你地图显示当前位置周边，点击展开地点文字。

手机承载聊天、记事本、行李和设置。照片、账单目前只有占位图标，点击不进入页面。锁屏轻按解锁，物理 Home 键退出手机并回到打开前的地图或游戏画面。页面本身固定，手机内容与游戏选项在各自区域滚动。

## 本地运行

无需生产依赖、打包或构建，在仓库根目录启动静态服务：

```sh
python3 -m http.server 4173
```

打开 `http://127.0.0.1:4173`。引擎测试需要 Node.js；浏览器检查另需 Playwright 及对应浏览器，命令与适用范围见[验证说明](docs/verification.md)。
