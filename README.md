# mi — 米米环游世界

`mi.fivsevn.com`

一个以现实旅行作为叙事环线的轻量像素网页游戏。

## v0.1 playable slice

- 世界地图 / Route 外壳
- AFRICA 42 DAYS 路线入口
- 三种初始行李方案与 20kg 限重
- DAY 01–05 可玩垂直切片
- 旅费 / 体力 / 行李变化
- 轻社交：`不知道为什么，突然想发给TA。`
- 三类朋友偏好、每日旅行记录、印章
- localStorage 自动存档
- 移动端优先，纯静态 HTML/CSS/JS

## Direction

完整版计划把每一次现实旅行做成一条封闭 Route。首条 Route 为约 42 天的非洲旅行；支持多周目，并在整段路线结束后形成约 9–13 种没有简单好坏区分的结局。

后续重点：真实 42 天路线数据、逐件行李箱、换装、机票/酒店选择、更多朋友与社交触发、完整结局系统、像素美术替换。

## Deploy

GitHub Pages from `main` / root. Custom domain: `mi.fivsevn.com`.
